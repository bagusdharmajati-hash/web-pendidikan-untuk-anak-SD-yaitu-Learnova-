## 🚀 Tentang Proyek

**Learnova** adalah aplikasi web interaktif yang dirancang untuk meningkatkan pengalaman belajar pengguna secara intuitif dan efisien. Dibangun menggunakan arsitektur monorepo/workspace modern dengan fokus pada performa yang cepat dan antarmuka pengguna yang responsif.
